Before authorizing a transaction

  1. Match the asset. Compare both currency and issuer. A familiar ticker or logo is not enough.
  2. Review both sides. Confirm the maximum spend and the exact or minimum amount to receive. A spending cap alone does not guarantee a minimum receipt when partial payment is enabled.
  3. Match your intent. Check the account, transaction type, destination, network fee and displayed verification memo in Xaman. Never approve a request you did not initiate.
  4. Confirm the result. A signature is not a validated success. Check the ledger outcome before retrying or changing an unresolved request.

Never enter a seed phrase, private key, secret numbers, wallet recovery phrase or API secret into a project webpage or support message.
